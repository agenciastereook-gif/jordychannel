# jordychannel

Sistema de producción para **Jordy en Vivo · El Hit · El Recorte**, pensado para una persona.

- `RUTINA.md` — la rutina diaria y semanal (empezá acá).
- `prompts/` — guion del short, dibujos, publicación, El Hit, El Recorte, video largo, clips.
- `scripts/srt_a_marcas.py` — SRT de TurboScribe → marcas de tiempo para los dibujos.
- `scripts/asignar_material.py` — copia tus fotos/videos a su marca de tiempo según `asignacion.txt`.
- `scripts/armar_video.py` — voz + dibujos/fotos/videos → video vertical u horizontal; también saca clips de un tramo.
