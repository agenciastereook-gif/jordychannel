# jordychannel

Rutina y herramientas para producir shorts de noticias de un canal de noticias con voz propia e
ilustraciones generadas por IA, sincronizadas por marca de tiempo.

- `RUTINA.md` — la rutina diaria paso a paso (empezá acá).
- `prompts/` — guion, imágenes, publicación.
- `scripts/srt_a_marcas.py` — SRT de TurboScribe → lista de marcas para el prompt de imágenes.
- `scripts/armar_video.py` — voz + imágenes nombradas por segundo → MP4 vertical u horizontal.
- `episodios/` — una carpeta por short (no se versiona el material pesado).
