# Prompt 3 — Empaquetado para publicar

Con el guion final de abajo, dame:

1. **Título YouTube Short** (máx. 60 caracteres, sin clickbait falso: la promesa se cumple en el video).
2. **Descripción** (2–3 líneas) + "Fuente: ..." + 3 hashtags.
3. **Texto para Reel de IG / TikTok**.
4. **Post para X** (máx. 280 caracteres) con el dato central.
5. Recordatorio: marcar en YouTube Studio si corresponde el aviso de contenido alterado/sintético
   (las ilustraciones tipo dibujo obviamente no realistas normalmente no lo requieren;
   si hay voz o imagen realista generada por IA, sí).
